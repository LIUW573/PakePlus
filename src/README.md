# 中文转南极语密文转换器

这是一个简单的网页应用，用于将中文文本转换为南极语密文。该应用专为移动设备优化，提供了简洁直观的用户界面。

## 功能

- 输入中文文本并转换为南极语密文
- 复制转换后的结果
- 移动端友好的响应式设计
- 配置管理（导入/导出/编辑）
- 外部JSON配置文件支持
- 本地存储配置信息（作为备份）
- 自动生成未知汉字的南极语单词

## 转换规则

- 每个汉字对应一个南极语单词
- 所有南极语单词的首字母大写
- 单词之间使用空格分隔
- 非中文字符保持原样
- 对于未定义的汉字，系统会自动生成南极语单词：
  - 使用该汉字拼音的首字母作为单词首字母
  - 随机生成剩余部分（主要使用辅音字母，避免与真实单词相似）
  - 自动将新生成的单词保存到配置中

## 使用方法

1. 在输入框中输入需要转换的中文文本
2. 点击"转换为南极语"按钮
3. 在下方查看转换结果
4. 如需复制结果，点击"复制结果"按钮

## 配置管理

### 配置文件
- 应用使用外部的`antarctic_config.json`文件作为主要配置源
- 如果配置文件无法加载，会自动从浏览器本地存储加载备份配置
- 新生成的单词会同时保存到本地存储中

### 编辑配置
1. 点击"编辑配置"按钮
2. 在弹出的模态框中修改JSON格式的配置
3. 点击"保存配置"按钮保存更改（会保存到本地存储）

### 导出配置
1. 点击"导出配置"按钮
2. 自动下载当前配置文件（antarctic_config.json）

### 导入配置
1. 点击"导入配置"按钮
2. 选择一个有效的JSON格式配置文件
3. 配置将自动应用并保存到本地存储

### 重新加载配置
1. 点击"重新加载配置"按钮
2. 应用将尝试从`antarctic_config.json`文件重新加载配置

## 本地运行

直接在浏览器中打开`index.html`文件即可使用。配置信息会保存在浏览器的本地存储中，同时也可以通过编辑`antarctic_config.json`文件来修改配置。
